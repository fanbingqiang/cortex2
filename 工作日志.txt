================================================================================
一、项目架构概述
================================================================================

Cortex2 是一个专注于 Java 后端面试的交互式学习平台，包含三大核心模块：

  ┌─────────────────────────────────────────────────────┐
  │            Vue3 前端 (localhost:5173)                │
  │  知识树练习 | 题库刷题 | AI 助手 | 个人中心 | 后台管理  │
  └────────────────────┬────────────────────────────────┘
                       │ HTTP API
  ┌────────────────────▼────────────────────────────────┐
  │         Java Spring Boot 后端 (localhost:8081)       │
  │  API 网关 | JWT 认证 | 数据库 CURD | 业务逻辑        │
  └────────┬───────────────────────────┬────────────────┘
           │ MySQL (localhost:3306)     │ HTTP
  ┌────────▼──────────┐  ┌─────────────▼───────────────┐
  │  MySQL 8.0 数据库  │  │  Python AI 服务 (8001)      │
  │  cortex2 库        │  │  FastAPI + DeepSeek LLM     │
  └───────────────────┘  └─────────────────────────────┘

  - Java 后端负责：认证、数据库、所有业务 API
  - Python 后端负责：LLM 调用、流式输出、Key 池管理、上下文压缩
  - Java 通过 HTTP 调用 Python，Python 调用 DeepSeek API

1.1 创建 Spring Boot 项目
  - 使用 Spring Boot 3.2.5 + JDK 17
  - 依赖：Spring Web, MyBatis-Plus, MySQL Connector, JWT, Lombok
  - 配置文件: src/main/resources/application.yml
    · 端口: 8081
    · 数据库: jdbc:mysql://localhost:3306/cortex2
    · 密码: ${MYSQL_PASSWORD:123456}（环境变量，默认 123456）

1.2 创建 Python AI 服务
  - 目录: ai-assistant-py/agent-engine-service/
  - 框架: FastAPI + Uvicorn (端口 8001)
  - 核心文件:
    · main.py - FastAPI 入口，注册路由
    · llm_client.py - LLM 客户端，多 Key 池管理，429 自动切换
    · pipeline.py - 教学流水线，上下文压缩，用户隔离
    · config.py - 配置管理（API Key, 限流参数）
    · models.py - 请求/响应模型
    · trace_store.py - 内存存储（会话、Prompt 模板）

1.3 创建 Vue3 前端
  - 目录: lab-frontend/
  - 框架: Vue 3 + TypeScript + Vite 5
  - 状态管理: Pinia
  - 路由: Vue Router (Hash 模式)
  - API 请求: Axios，baseURL = /api/lab

5.1 多 Key 池管理
  - 配置: LLM_API_KEY 支持逗号分隔多个 Key，如 "sk-xxx,sk-yyy"
  - 策略: 选择当前 RPM 使用最低的 Key
  - 429 处理: 自动切换到下一个 Key 重试
  - 队列: 所有 Key 都忙时，请求入队，最大队列长度 200

5.2 上下文压缩
  - 触发条件: 历史消息超过 10 条
  - 策略: 保留最近 5 条，压缩较早的 15 条为 LLM 摘要
  - 实现: pipeline.py 中的 compress_history 方法

5.3 用户隔离
  - 每个用户独立的历史记录，通过 user_id 隔离
  - 对话存储在 assistant_conversation 和 assistant_message 表
  - JWT 提取 user_id，严格校验所有权

5.4 前端改动
  - GlobalChat.vue: 隐藏「配置」按钮和 ConfigPanel 组件
  - API Key 预填在服务端，用户无需手动输入
  - 移除 max_tokens 限制（llm_client.py 中 3 处 max_tokens=4096 删除）

5.5 笔记功能
  - pipeline.py 修改笔记格式为基础知识点（标题、答案摘要、关键点）

  - 支持编辑（双击或 ✎ 按钮）和删除（✕ 按钮）

9.5 关键 Bug 修复：Java HttpClient 请求体丢失（HTTP/2 升级）
  - 现象: Java 调 Python /api/chat/simple 时，Python 收到 Content-Length 存在但 body 为 0
  - 根因: Java 17 HttpClient 默认发送 `Connection: Upgrade, HTTP2-Settings` + `Upgrade: h2c`
         尝试 HTTP/2 升级，uvicorn/httptools 对该请求丢弃 body
  - 修复: PythonAIService.java 强制 HTTP/1.1（.version(HTTP_1_1)）+ 绕过系统代理直连
  - 影响: 修复后 AI 知识卡片生成等所有 Java→Python 的 POST 调用恢复正常

阶段 11: 代码沙箱安全加固
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

11.1 背景
  - 编辑器"运行代码"原实现：本机 javac/java 直接执行（仅临时目录 + 超时）
  - 风险：代码直跑服务器，Runtime.exec / Socket / 内存炸弹 / 删文件等可破坏宿主机

11.2 三层防护（SandboxService.java 重构）
  - 第 1 层 资源限制：代码 ≤ 300 行、≤ 100KB，超限直接拒绝
  - 第 2 层 危险 API 拦截：正则扫描 System.exit / Runtime / ProcessBuilder / exec /
           Socket / URLConnection / 删文件 / shutdownHook / Unsafe 等 17 项，
           命中即拒绝并提示（已排除 getClassLoader 等教学常用 API 防误伤）
  - 第 3 层 Docker 容器隔离：docker run --rm --network none --memory 256m
           --cpus 0.5 --pids-limit 100，挂载临时目录编译+运行，禁网限资源
           （与力扣/LeetCode 同款做法），镜像 eclipse-temurin:17-jdk

11.3 双模式降级
  - 启动时检测 Docker 可用 → 容器执行
  - Docker 不可用 → 回退本机执行（保留第 1/2 层限制），日志告警"禁止用于生产"
  - 执行超时 30s（Docker）/ 编译 15s + 运行 10s（本机），超时强杀 + docker kill 兜底
  - 异步读子进程输出，避免管道缓冲区写满死锁

11.4 验证
  - mvn compile 通过
  - 拦截正则 11 个用例全过（恶意代码全拦、教学代码零误伤）

五、如何复刻这个项目

5.1 环境准备
  ┌─────────────────────────────────────────────────────────────┐
  │ 1. 安装 JDK 17+   (https://adoptium.net)                   │
  │ 2. 安装 Maven 3.6+ (https://maven.apache.org)              │
  │ 3. 安装 MySQL 8.0  (https://dev.mysql.com/downloads)       │
  │ 4. 安装 Python 3.11 (https://www.python.org/downloads)     │
  │ 5. 安装 Node.js 20  (https://nodejs.org)                   │
  │ 6. (可选) 安装 Docker Desktop                              │
  └─────────────────────────────────────────────────────────────┘

5.2 数据库初始化
  # 启动 MySQL（端口 3306）
  mysql -u root -p123456

  # 创建数据库
  CREATE DATABASE cortex2 DEFAULT CHARACTER SET utf8mb4;

  # 导入初始化脚本
  mysql -u root -p123456 cortex2 < init-mysql.sql

5.3 启动 Python AI 服务
  cd ai-assistant-py/agent-engine-service
  pip install -r requirements.txt
  python main.py
  # 服务运行在 http://localhost:8001

5.4 启动 Java 后端
  # 设置环境变量（Windows PowerShell）
  $env:MYSQL_PASSWORD = "123456"

  # 编译并启动
  cd cortex2
  mvn clean package -DskipTests
  mvn spring-boot:run
  # 服务运行在 http://localhost:8081

5.5 启动前端开发服务器（可选）
  cd lab-frontend
  npm install
  npm run dev
  # 开发服务器运行在 http://localhost:5173

5.6 访问项目
  ┌──────────────────────────────────────────────────────┐
  │ 前端页面:  http://localhost:8081/lab/                │
  │ 后台管理:  http://localhost:8081/lab/#/admin         │
  │ Swagger:   http://localhost:8081/swagger-ui.html     │
  │ Python:    http://localhost:8001/docs                │
  └──────────────────────────────────────────────────────┘

5.7 使用 Docker 启动（推荐，一键）
  # 方式一：双击 start.bat（自动检查 Docker → 构建镜像 → 启动全部服务）
  # 方式二：手动命令
  # 确保 Docker Desktop 已启动
  docker compose build        # 首次构建（Java 镜像需先有 target/*.jar）
  docker compose up -d        # 后台启动全部服务
  # 访问 http://localhost:8081/lab/
  # 停止：双击 stop.bat 或 docker compose down

七、常见问题排查
================================================================================

Q: 登录失败，返回 500？
A: 检查 MYSQL_PASSWORD 环境变量是否设置，或 application.yml 中默认值是否正确。

Q: 知识树节点点击不生成代码？
A: 确保 Python AI 服务在 8001 端口运行。
   检查 TreeNode.vue 的 onSelect 函数是否去掉了 isLeaf 限制。

Q: 题库数据清空后又回来了？
A: 检查 @PostConstruct 注释是否完整，有 4 个种子方法需要注释掉。

Q: API 返回 404？
A: 检查接口路径是否正确，所有 Lab 接口前缀为 /api/lab/。

Q: AI 助手提示"请先注册或登录"？
A: AI 助手接口需要 JWT 认证，匿名用户不能使用。
