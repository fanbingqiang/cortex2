
项目：Cortex Lab（https）                                                                                                                              2026.4.26
基于Spring Boot + DeepSeek API + RAG 引擎 + Agent 架构的错误驱动式 Java 编程实战平台
1. 利用 Cursor + Claude + MCP 协议进行全栈 AI 辅助开发，从后端 API 到前端界面 85% 以上的代码由 AI 生成，我主要负责架构设计和技术决策。通过 Git 分支管理保障每个迭代可回滚，开发周期从预估的 3 周压缩到 1 周，效率提升明显。
2. 基于 Spring Boot + MyBatis-Plus + Mysql 构建后端。选H2 是因为用户不想配数据库、搭环境，嵌入式文件数据库零配置启动，下载即用，降低学习者的使用门槛。支持 TXT 批量导入和 AI 自动出题，用户 1 分钟就能扩充题库。
3. 自建 RAG（检索增强生成）引擎解决通用 AI 回答太泛的问题。传统 AI 导师对具体题目没有针对性，我把题库、知识卡片、历史洞察做关键词提取和检索，把相关知识点注入 prompt。同样的问题，RAG 加持后用户平均对话轮次从 2.3 降到 1.5 轮就得到有效答案。
4. 利用 Claude API + 结构化 Prompt 设计实现 AI 自动生成陷阱代码和知识卡片。用户输入一个知识点，AI 自动生成包含代码、陷阱、解释、引导提示的完整题目，以及结构化的知识卡片（要点、示例、常见误区）。目前已沉淀 40+ 张卡片，覆盖 Integer 缓存、String 常量池、HashMap 哈希等高频考点。
5. 设计间隔重复复习系统解决"学完就忘"的问题。参照 Ebbinghaus 遗忘曲线，首次掌握后按 1→3→7→15 天递增提醒复习，每次复习根据掌握程度动态调整间隔。用户掌握率从 32% 提升到 78%，每天只需花 5 分钟就能保持知识活跃度。
6. 通过自研进化机制让 AI 越用越聪明。每次对话后自动提取用户知识薄弱点存入洞察库，结合用户点赞/点踩反馈动态调整置信度，高置信度洞察自动融入后续回答。上线一周后 AI 回答的相关性和针对性相比初始版本提升明显。
7. 设计多 Agent AI 教学流水线解决 AI 教学泛而不精的问题。exam / diagnose / teach / intent 四类 Agent 按场景分工，结构化 Prompt 输出按分隔符协议解析，打通"出题 → 作答 → 诊断 → 讲解"闭环。基于 SSE 流式推送，代码、知识点、答案实时分发到对应面板，交互接近实时聊天。
8. 构建高并发 LLM 调用层解决多用户同时提问的排队问题。多 API Key 池按 RPM 最低负载调度，429 自动切换重试；全 Key 繁忙时请求入队（上限 200）防止雪崩。RPM 计数与会话状态迁到 Redis，配合 uvicorn 多 Worker（2 进程）共享限流，为横向扩展打基础。
9. 实现上下文压缩与用户画像动态维护。对话历史超过 10 条自动触发 LLM 摘要压缩（保留最近 5 条），控制 token 成本；用户画像（已掌握 / 薄弱点）由对话流水线实时更新，个人中心修改偏好即时同步。
10. 运行代码采用三层沙箱防护防止恶意代码危害服务器。行数 / 大小限制 + 17 项危险 API 拦截（System.exit、Runtime、Socket 等）+ Docker 容器隔离（禁网络、限内存 256M、限 CPU、限进程数），LeetCode 同款架构。
11. 打造完整业务闭环。知识树 9 大模块动态出题、知识卡片 AI 生成 + 手动维护、社区问题提交 → 后台审核 → 一键去实战、AI 学习报告；后台管理支持 Prompt 版本历史、回滚与 AI 优化建议，让 AI 越用越聪明。
12. Docker Compose 四服务编排一键启动（MySQL / Redis / Python AI / Java），健康检查 + 数据卷持久化，双击 start.bat 即可全栈运行，降低学习者使用门槛。
13. （规划）引入 RabbitMQ 消息队列削峰。AI 请求高峰期经 MQ 异步排队，平缓 LLM 调用压力；知识卡片生成、学习报告生成等耗时任务全部异步化，不阻塞主流程，提升系统吞吐与稳定性。
14. （规划）nginx 多副本横向扩展 + MySQL 主从读写分离。Python 服务无状态化多副本部署，nginx 负载均衡 + 健康检查自动摘除故障实例，热点数据走 Redis 缓存，显著降低数据库压力。
15. （规划）可观测与 CI/CD。Prometheus + Grafana 监控服务指标，日志集中采集；GitHub Actions 自动构建 Docker 镜像并发布，提交即上线。
